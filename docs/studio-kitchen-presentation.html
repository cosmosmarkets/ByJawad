03 Rotating Suffix Hero Spec

The Hero Section (#hero) sits on a prominent red poster grid. It uses a crossfading word rotation mechanism that falls back gracefully to a static headline on reduced motion.

Hero Component Specs

Hero Background
color.heat.red (#E63946) with 24px linear grid using dark red overlay (#C1121F) at 35% opacity.
Rotator Logic (v2)
Rotates suffix words ["portfolios", "landing pages"]. Opacity fades out/in over 400ms, holding for 4000ms.
Reduced Motion Fallback
"The kitchen for mouth-watering portfolios and landing pages" (combined static headline). Suffix rotation is disabled.
Button Mechanics
3px black borders. Active click translates button by translate(4px, 4px) and removes offset shadow. Gives a chunky physical feedback.

06 CTA Model & Conversion Flows

Sitewide CTAs route visitors efficiently based on intent. Red surfaces have high-intent CTAs (Place your order), while cream surfaces use global CTAs (Chat to the chef).

Conversion Persona

1. Proof Path (Organic) Visitor reviews portfolio proof first, qualifies build quality, then books call.
2. Scroll Path (Scroller) Visitor bypasses work clicks, reads process & tools, converts at reservation poster.
3. High Intent Path Fast-track action via Hero or Navigation CTA within 5 seconds.
4. Qualification Path Visitor clicks service package why-tiles to check freelancer vs SaaS suitability.

Proof Path Flow

A detailed walk-through of the step-by-step visitor route to qualification.

Visitor scans the red hero and scroll straight to the "My dishes" selected work section. They inspect the "By Jawad" card, click view project, see the case study, and are routed to the contact form.
Important CTA Color Rule

Place your order CTA is restricted to RED surfaces only (Hero, reservation poster). Headers and cream strips must use Chat to the chef or Book a Call with white/black pills.

07 Wireframe Handoff & v2 Roadmap

The project is pre-build scaffolding. Use the checklist below to verify wireframe exit criteria before implementing the full React site.

v1 Wireframe Handoff Checklist

Desktop (1200px) & Mobile (375px) layouts conform to homepage-wireframe-spec.html.
Scroll order locked: nav → hero → trust → why-order → work → process → tools → cta → footer.
Option B work applied: 1 live project card + 1 coming soon card. No mock fillers.
CTA destinations match: Red surfaces link to `/order` (high-intent), nav links to `/order` or Calendly.

Deferred to Wireframe v2 (Hi-Fi)

  • Nav scrolling effects: Shrink and blur transitions on scroll.
  • Hero suffix rotation: Crossfade animations (demo on slide 3).
  • Interactive hovers: Chunk offset translation shadow on dishes and pantry items.
  • Real Brand assets: Monogram logo, custom illustrations, and project screenshots.
  • Supabase Integration: Live contact database and Resend email forms.
  • v2 Testimonials strip: To be added when 2+ client reviews exist.
