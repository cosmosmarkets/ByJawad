Format Shift: Scrollable HTML
Unlike v1 (which used side-by-side static 1200px and 375px dual frames), v2 uses one responsive scrollable page per route. This allows reviewer-interaction simulation.
Step-by-Step Review Guide
  1. Serve locally: npx --yes serve "docs/wireframes-v2" -p 3000
  2. Verify at key viewports: 375px (mobile) · 900px (tablet) · 1200px (desktop).
  3. Exercise scroll height shrinks, drawer panel escape keys, button active presses, and accordion toggles.

Wireframe v1: Structure & Section Order

Format: Grayscale dual static frames (1200px + 375px)

Locked Deliverables
Section order, anchor structures, verbatim copy lines from markdown briefs, dual-frame layouts, and base CTA directions (e.g. order flow redirecting to /order).
Deferred / Ignored Features
All color variables, font families, scrolling states (sticky headers, drop blur), animation crossfades, form validation styles, accordion toggling.
Pipeline Gate Rule
"Do not start the next stage until the current stage passes its exit checklist."
This prevents layout regression and prevents developers from guessing scroll and hover interactions during mid-fi construction.
