## Global CTA Hierarchy

Sitewide actions are split into **persistent** (always available) and **contextual** (page/section-specific). Kitchen-themed labels are used where intent stays clear; conversion-critical actions stay plain.

| Tier | Label | Destination | When to use |
|------|-------|-------------|-------------|
| **Global primary** | Book a Call | `/contact` (Calendly anchor) | Header, footer, end-of-page bands on all key pages |
| **Global secondary** | Start an Inquiry | `/contact` (form anchor) | Header (optional), footer, case study ends, services ends |
| **Hero primary** | Place your order | `/contact` | Homepage hero only |
| **Hero secondary** | See what's cooking | `/work` | Homepage hero only |
| **Proof primary** | View Case Study | `/work/[slug]` | Work grid cards, homepage selected work |
| **Proof secondary** | Start a Project | `/contact` | Work page header/footer |
| **Offer primary** | Book a Call | `/contact` | Services page (same as global) |
| **Offer secondary** | Start an Inquiry | `/contact` | Services packages, FAQ end |
| **Authority primary** | Read Case Studies | `/work` | Journal index, article mid-content |
| **Authority secondary** | Book a Call | `/contact` | Journal article end |
| **Recovery** | Return home | `/` | 404 page |
| **Recovery** | See what's cooking | `/work` | 404 page |
| **Recovery** | Place your order | `/contact` | 404 page |

## Section-Level CTA Pattern

Repeat this rhythm on long pages to maintain conversion momentum without fatigue.

| Position | Typical label | Typical destination |
|----------|---------------|---------------------|
| **Mid-page (after proof)** | View Services | `/services` |
| **Mid-page (after offer)** | See what's cooking | `/work` |
| **End-of-page band** | Book a Call + Start an Inquiry | `/contact` |
| **Footer** | Book a Call (button) + nav links | `/contact` |

---

## Kitchen-Themed vs Plain Labels

Use kitchen-themed labels when the **next step is obvious** from context. Use plain labels when **friction or ambiguity** would hurt conversion.

| Use kitchen-themed | Use plain |
|--------------------|-----------|
| Place your order (hero → contact) | Book a Call |
| See what's cooking (→ work) | Start an Inquiry |
| Section kickers (From the pass, The recipe) | Send project brief (form button) |
| Return home (404) | View Services |
| Work With Me (about — clear intent) | Book a 15-min call (Calendly) |
| Get the recipe (newsletter) | Subscribe |

**Avoid:** Enter Orbit, Beam Me Up, Go Cosmic, Ignite — retired space labels.
