# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-22

### Added
- Initial release with 15 commands and 12 rules
- Commands for component creation, forms, testing, optimization
- Rules for React, Next.js, TypeScript, performance, security, SEO
- Comprehensive documentation (README, USAGE, CONTRIBUTING)
- GitHub Sponsors support

### Commands
- `/create-component` - Create React components
- `/create-form` - Forms with React Hook Form + Zod
- `/create-server-component` - Next.js Server Components
- `/create-server-action` - Next.js Server Actions
- `/create-api-client` - Type-safe API client
- `/add-tests` - Generate RTL tests
- `/refactor-component` - Code quality improvements
- `/review-code` - Code review checklist
- `/optimize-performance` - Performance optimizations
- `/audit-accessibility` - Accessibility audit
- `/setup-zustand-store` - State management
- `/setup-dark-mode` - Dark mode implementation
- `/setup-env-variables` - Environment variables
- `/create-responsive-layout` - Responsive design
- `/prepare-production` - Production checklist

### Rules
- `react-typescript.mdc` - React & TypeScript standards
- `nextjs-app-router.mdc` - Next.js 14+ patterns
- `file-organization.mdc` - File structure conventions
- `testing.mdc` - Testing standards
- `component-patterns.mdc` - Component templates
- `nextjs-patterns.mdc` - Next.js templates
- `form-patterns.mdc` - Form patterns
- `testing-patterns.mdc` - Test templates
- `performance-optimization.mdc` - Performance patterns
- `security-patterns.mdc` - Security best practices
- `responsive-design.mdc` - Responsive patterns
- `seo-patterns.mdc` - SEO and meta tags
- `animation-patterns.mdc` - Animation patterns
